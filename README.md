GLORIOUS-HACK — Ethical Security Toolkit

Motto: Think Beyond. Build the Future.

Mission: Learn cybersecurity responsibly using Android and Termux.

About

GLORIOUS-HACK is a Python-based toolkit for learning about network diagnostics, website checks, password security, file integrity, and basic security auditing.

Features

- Network information and DNS lookups
- Basic port and website checks
- Password strength checking and secure password generation
- HTTP headers, redirects, and TLS checks
- Website security configuration checks
- File hashing and integrity verification
- Link status and uptime history checks
- Basic security reports and audit logs
- Local file and metadata inspection

Requirements

- Android device
- Termux
- Python 3
- Internet connection for online checks

Installation

Open Termux and run:

pkg update
pkg install python
cd ~/GLORIOUS-HACK

Run the Toolkit

python glorious.py

Follow the numbered menu to select a tool.

Syntax Check

python -m py_compile *.py

No output normally means the Python files passed the syntax check.

Responsible Use

- Test only systems you own or have explicit permission to assess.
- Never collect, expose, or share other people's passwords or private data.
- Use public website checks responsibly and respect service limits.
- Treat scan results as clues, not proof that a system is secure or vulnerable.
- A clean result from a local malware indicator checker does not guarantee that a file is safe.

Project Status

This project is under development. Features and results may vary depending on Android, Termux, network access, and installed dependencies.
